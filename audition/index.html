A key pressed fires a burst, held keeps the cloud going, released lets it ring out. A USB MIDI keyboard plays with velocity (Web MIDI: Chrome / Edge / Firefox); CC 20–27 move the first eight parameters, CC 7 the level, CC 64 (the sustain pedal) holds the notes, the mod wheel (CC 1) moves INTENSITY and the pitch wheel PROXIMITY (centre = the preset's own). An SMK-37 (or any keyboard) as a controller: MIDI learn, click a slider, move a knob, fader, wheel or pad that sends a CC; the map is kept in this browser.

Lane mode: the keyboard shows C4 … C6. The 15 white keys are the selected lane's activity fader (C4 the least, still sounding; C6 massive; a move glides in over ~1 s); the 10 black keys C#4 … A#5 pick a lane (the first four here, or the number keys 1–4); tapping the selected lane's black key again starts or stops it. A running lane generates on its own (no key held). The white keys light up as the bar, the chosen lane's black key is lit, the other running lanes' black keys glow. Computer letters (Z X octave) and a MIDI keyboard (notes 60–84) play the same keys.
